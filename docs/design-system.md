## 1. Общие принципы

- Стиль интерфейса **строгий**, **минималистичный** и **функциональный**.
- Акцент на **данных**, **формах** и **удобстве**, а не на декоративности.
- **Единообразие** между сервисами **обязательно**.
- Дизайн отдаёт приоритет **ясности**, **предсказуемости** и **эффективности**.

---

## 2. О руководстве и области применения

- Документ — **справочное издание** со **стандартами** и **обязательными** требованиями к оформлению сервисов инфраструктуры **ИСОД МВД России**.
- Цель — **стилистическое и оформительское единообразие** одного сервиса и всей инфраструктуры.
- **Десктоп** и другие сервисы оформляются по руководству; при необходимости **дополняются** элементами, здесь не описанными, с сохранением **стилистики и узнаваемости**.

## 6. Цвета

### 6.1. Дисклеймер по кодам

> В извлекаемом тексте PDF **нет** числовых значений (HEX, RGB, CMYK) для основного синего, красного, зелёного, тёмно-синего и градиентов — они даны **только визуально** на стр. 5–7. Ниже — **ролевая модель**; точные коды снимают с PDF/исходников или запрашивают у автора гайда.  
> **Точные веб-цвета** в тексте руководства указаны **только для ссылок** (стр. 39) — см. §15.

### 6.2. Палитра бренда (семантика из текста руководства)

| Роль | Цвет / тип | Использование |
|------|------------|----------------|
| Основной | **Синий** | сплошные заливки |
| Дополнительные | **Красный, зелёный, серый, тёмно-синий**, оттенки | поддержка композиции |
| Акцент | **Красный** | акценты; вместе с синим усиливает бренд |
| Акцент заголовков | **Градиент красный → синий** | заголовки, требующие внимания |
| Нейтральные | **Оттенки серого** | фон без «шума», ощущение целостности |
| Фон UI и иконок | **Фирменные градиенты** (отдельно от градиента заголовков) | фон элементов и иконок |

### 6.3. Краткая сводка (для быстрого ориентира)

- **Синий** — основные элементы и фоны.
- **Красный** — выделение и важные действия.
- **Зелёный** — позитивные действия (в т.ч. кнопки успеха; точные HEX в PDF не зафиксированы).
- **Серый / тёмно-синий** — нейтральная структура и вариации композиции.
- Градиент **красный → синий** — допускается для акцента (например, шапки).

## 7. Типографика и редакция

### 7.1. Гарнитура и масштаб

- Основной шрифт: **PT Sans**.
- Заголовки H1–H5 — кегли как в **§3**; в оригинале для заголовков — **капитель**, в меню — без капители; в реализации допустимо опираться на **жирное** начертание по согласованию с макетом.
- Основной текст: **14 px**, межстрочный интервал **22 px**.
- В интерфейсе **избегать** излишне сложной типографики.
- **Без красной строки** у абзацев в экранной вёрстке.

### 7.2. Кавычки

- В русском тексте: **«ёлочки»** или **„лапки“**.
- В интерфейсах ИСОД МВД России **рекомендованы «ёлочки»**.

### 7.3. Красная строка и выключка

- В **экранной** типографике **не рекомендуется** красная строка и **выключка по всей ширине** «как в книге».

### 7.4. Тире, минус, дефис (стр. 49)

| Знак | Пример |
|------|--------|
| **Тире** | МВД России **—** это… |
| **Минус** | 2 **−** 1 = 1 |
| **Дефис** | по**-**русски, какой**-**либо |

Различаются **областью применения** и **длиной** черты.

### 7.5. Набор текста: неправильно / правильно

- **Неправильно:** расставленные пробелами буквы в словах, «разъехавшийся» набор абзаца.
- **Правильно:** непрерывный нормальный набор.

### 7.6. Рекомендуемые словари (стр. 50)

1. «Справочник издателя и автора», 3-е изд., испр. и доп., М., 2009 — Мильчин А.Э., Чельцова Л.К.  
2. Справочник по правописанию и литературной правке / под ред. И.Б. Шляховой, 8-е изд., испр. и доп., М., 2009 — Розенталь Д.Э.  
3. Толковый словарь русского языка, 4-е изд., доп., М., 1999 — Ожегов С.И., Шведова Н.Ю.

## 9. Навигация

### 9.1. Общее (стр. 11–12)

- Навигация учитывает разные сценарии, но остаётся **унифицированной** между сервисами.
- Типы: **горизонтальная** и **вертикальная**.

### 9.2. Горизонтальная навигация (стр. 12–17)

| Тема | Правило |
|------|---------|
| Типовой объём | **5–6** пунктов меню |
| ≤ 5 пунктов | Ячейки **одинаковой ширины**; ссылка + иконка **по центру** ячейки |
| 5–6 пунктов | Фиксированные отступы слева и справа **внутри** ячейки; ширина ячейки **динамическая** |
| Переполнение | Лишние ссылки — в **выпадающем** меню (наведение/клик) |
| Поиск | Пиктограмма поиска **справа** от ссылок меню; отдельно — состояния после клика и после ввода запроса |
| Второй уровень | Не более **7** ссылок |
| Мегаменю | **1–4** колонки; по наведению на пункт **1-го уровня** |
| Две колонки | Вариант выпадающего меню 2-го уровня; группы ссылок в 1-й колонке |

### 9.3. Вертикальная навигация (стр. 18)

| Тема | Правило |
|------|---------|
| Назначение | Административные сценарии, много разделов «на виду» |
| Роль | основная или дополнительная |
| 2-й уровень | ссылки можно сгруппировать в **2 колонки** |

### 9.4. Хлебные крошки (стр. 19)

- **Обязательны** для интерфейсов сервисов ИСОД МВД России.
- Показывают **текущее местоположение** пользователя в иерархии.

## 10. Формы и ввод данных

### 10.1. Размеры полей (сводка)

См. **§3** (высота, скругление 3px, отступ плейсхолдера 12px / 14px для авторизации, кегли).

### 10.2. Компоненты и поведение (стр. 22–26)

| Компонент | Спецификация |
|-----------|--------------|
| **Многострочный ввод** | Большие тексты, описания |
| **Календарь с периодом** | Выравнивание по **правому краю** инпута-источника |
| **Диапазон (ползунки)** | Плавный режим или пошаговый по сетке |
| **Выпадающий список** | Допускается **свой вариант** помимо предустановленных |
| **WYSIWYG** | В CMS; панель **ограничена**, чтобы не нарушать гайд |

### 10.3. Обязательные поля (стр. 26)

| Элемент | Правило |
|---------|---------|
| Маркер | **`*` слева** от названия поля |
| Текст перед формой (обязателен) | «**Поля, отмеченные *, обязательны для заполнения.**» |

### 10.4. Типы полей (чеклист)

- Однострочный ввод, textarea, дата, диапазон, выпадающий список, список с поиском, WYSIWYG.

## 12. Кнопки

### 12.1. Размеры и кегли

См. **§3** (40 / 32 / 26 px; кегли 16 / 14 / 13 px; текст по центру по горизонтали).

### 12.2. Ограничения по акценту (зелёный / красный)

| Тип | Правило |
|-----|---------|
| **Большие** (в т.ч. авторизация) | Не больше **одной** зелёной **или** красной одновременно |
| **Стандартные** | То же |
| **Маленькие** | **Исключение:** может быть **несколько** одного цвета |

*(Точные HEX зелёной/красной в тексте PDF не приведены.)*

### 12.3. Прочие паттерны

- С **иконками** — различение по смыслу при визуально похожих кнопках.
- **Указатели** — обозначают поведение формы после нажатия.
- Загрузка файлов — см. **§19**.

- На экране в целом — **одно основное действие** (согласовано с §22); не плодить конкурирующие акценты.

## 21. Правила UX

- Ясность важнее внешнего «украшательства».
- Без **лишней** анимации.
- Без излишне **сложных** взаимодействий.
- **Предсказуемое** поведение на разных страницах.

---

## 22. Ключевые ограничения

- **Одно** основное действие на экран (в паре с правилами акцентных кнопок, §12).
- Навигация **предсказуема**.
- Вёрстка **по сетке** (§4).
- UI **согласован** между сервисами.

---

## 23. Рекомендации по разработке и архитектура

- Компоненты соблюдают заданные **размеры** и **отступы**.
- Не отклоняться от **типографической шкалы** без необходимости.
- Новые стили — после **согласования**.
- **Переиспользуемые** компоненты для типовых элементов UI.
- **Обёртки** над примитивами библиотеки: Button, Input, Table, Modal.
- На страницах **не** использовать сырые компоненты UI-kit напрямую (политика проекта).
- **Централизовать токены:** цвета, отступы, типографика (единый источник в коде).
